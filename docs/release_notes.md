# BRAN code release 0.2.0

This release adds the original research code and a usable model interface to the initial architecture package.

## Included

- The retained architecture with checked source hashes.
- A documented clinical input contract with 59 slots and nine CBC targets.
- A tensor-only checkpoint interface with binding checks, target erasure and explicit abstention.
- Generated-input train, save, reload and inference examples.
- Original training and evaluation code in a 425-module source snapshot with an entrypoint map.
- Synthetic checks of the model interface and original AUROC bootstrap kernel.
- A portable Python renderer for locally supplied figure specifications.
- MIT licensing, software citation metadata and automated synthetic checks.

## Scope

No patient data, retinal images, individual embeddings, predictions, bootstrap draws, weights, fitted transforms or research-result tables are included. The figure renderer expects locally supplied inputs. The research snapshot retains historical source paths and authentication checks.

This is not a pretrained model download. Reproducing reported clinical results requires authorized datasets and compatible private research artifacts. Six variable-driven import sites across four historical modules remain documented in the reproduction guide. Synthetic tests and code checks do not substitute for clinical validation.
