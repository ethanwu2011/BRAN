This page is generated by `python tools/source_data_coverage.py` from the Source Data in `paper/source_data` and the file names in `research/`. Do not edit it by hand. `python tools/source_data_coverage.py --check` fails when it is stale or when a Source Data source has no entry.

Every Source Data row names the aggregate file its values were read from. The tables below group those files by the run that wrote them and say whether the code of that run is in `research/`. A row read from two files counts under the less complete of the two.

Of 1,865 Source Data rows, 590 come from analyses whose code is in `research/`, 32 quote text records that no analysis computed, and 1,243 come from analyses whose code is not yet in this repository.
